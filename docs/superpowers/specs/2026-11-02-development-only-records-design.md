# 실제 개발 변경만 자동 기록

사용자 요청: Git 수정이 있는 개발 작업만 정리해 Space와 다이어리에 반영한다. 검색·견적·비교·설명·탐색은 기록하지 않는다. 이전 Google 캘린더 조사 기록은 이미 로컬 저장 및 Space 게시 시도가 있었으며 기존 자료는 삭제하지 않는다.

기록 후보는 작업 시작 커밋, 완료 커밋, 해당 작업의 변경 파일을 명시한다. 로컬 Git에서 두 커밋의 선후 관계와 실제 파일 변경을 확인한다. 소스·테스트·빌드/설정 변경이 하나 이상 있어야 한다. 문서만 작성하거나 다른 작업의 변경을 가져와 조사 기록의 근거로 사용하지 않는다. 커밋 전에는 기록을 준비하지 않는다.

지침만 고치는 방식은 호출 실수를 막지 못하므로 prepare와 sync에 로컬 검사를 함께 둔다. Git 근거가 없는 후보는 다이어리/Space 호출 전에 제외한다. 기존 완료 기록과 편집 충돌은 보존하고, 근거 없이 남은 과거 대기 기록은 재시도 대상에서 제외한다. 새 기록을 만드는 대신 같은 작업 ID를 유지하며, 요약은 현재 대화의 원문 문단을 재사용한다.

이번 변경은 전송 조건을 제한하는 0.8.1 수정이다. 머지는 사용자 테스트 승인 이후에 한다.
