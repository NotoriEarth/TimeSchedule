# 0.8.0 작업 종료·오프라인 기록 후속 검증

사용자 요청에 따라 별도 오전 9시 자동화 `timeschedule`을 PAUSED로 전환했다. 작업 종료마다 다이어리에 전체 원문을 먼저 남기고, 앱 실행 중 대기 기록만 자동 재시도한다. 연결 후에는 원문을 유지하면서 같은 항목에 검증된 Space 링크를 붙인다.

2026-10-31 자동 검증: Rust workspace 114개(코어 35·플랫폼 12·네이티브 67) 통과, 기존 의도적 제외 2개. Node 전체 16개 통과. Rust fmt·Git diff 검사 통과. 디버그 EXE 빌드 성공.

새 검증은 링크 없는 원문 저장→같은 항목 링크 연결, v1 입력 호환, 연결 실패와 재시도 간격, 여러 누적 작업, 같은 작업의 후속 수정 순서, 오래된 링크 전달이 최신 로컬 내용을 덮어쓰지 않음, 다른 작업의 독립 진행, 앱 재시도 프로세스의 단일 실행·대기 시각 검사를 포함한다. 구현 전 실패를 확인한 테스트가 수정 후 통과했다.

실제 Space 연결 복구·최종 실행 파일과 독립 검토 결과는 완료 후 이 문서에 추가한다. 실제 사용자 클릭·한글 입력의 육안 확인과 PR 병합 승인은 별도다.
